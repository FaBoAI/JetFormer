出し方 1〜3 では、速度ゲインが制御器のスロットル(目標速度の追従)にも掛かります(1.0 を勧めます)。速度の上限はゲインに関係なく効きます

            
出し方 1〜3 は試験的です。制御器のスロットルの写像はまだ粗く(正解の目標速度を入れても人との相関 0.5 程度)、比較で評価したのは「操作の枝だけ」です
