## 4. 新しい問題 B: 学習除外がシーンタブを通ると漏れる

`e2e_label_mask.py`: ベストラップの記録(`data/datasets/jetformer-simulator-rl-bestlap-20min_…`)の 2 シーンを写し、frames.jsonl の各行に新しい開始の F2-P の有効な回(Q2・Q4)の
`l` を `action_info.jf` として入れ(Q4 は 3 章の止まりの回で出来事 0。info を消す確かめに使った)、session.json の teacher を `jetformer-sim-rl-teacher/v1` にし、2 つ目のシーンの 300 フレーム目の info を消して tar にした。
一時フォルダ(config.DATA_DIR・DATASET_DIR・RAW_DIR を差し替え)で `import_archive(…, to_scenes=True)` → 展開したシーンで `build_dataset` → `update_scene(mode_id=8)`。

| 確かめ | 結果 |
|---|---|
| npz のフレーム k と frames.jsonl の frame の対応(ベストラップの 5 シーン) | vehicle[k] = applied_pwm_us[k](差 6e-5 µs)、future_actions[k] = applied[k+1..k+10]。外す範囲 k ∈ [j − 10, j − 1] は正しい |
| 取り込み: future_valid・mode = 0 が決まりどおり | 2 シーンとも一致(外した観測 116・10)。最後の 10 フレームの False は元のまま、vehicle_valid と他の配列は変わらない |
| 取り込み: 学習に使う観測の正解に l = 0 の操作 | **0**(474・580 観測) |
| fail closed(info を消した 1 行) | その前の 10 観測が外れ、注意に出た。カードの label_mask・training_frames(1,054)も合う |
| シーンタブへの展開 | 外した区間は「未設定」のジャンルの区間として残る(4 区間・1 区間) |
| **展開したシーンから作り直したデータセット** | 正解の時刻の引き方で、観測の 67%(393/589)の正解の少なくとも 1 つが 1 フレーム前にずれる。出来事 4 つのシーンで、学習に使う観測 k = 370(= pe − 1)の正解の 1 つ目が乱した操作(フレーム 370)。**1 つ目の正解がずれる観測は 33% なので、出来事のおよそ 3 つに 1 つで 1 観測が漏れる見込み** |
| **シーンタブでジャンルを付け直す**(`update_scene(mode_id=8)`) | 9 区間(未設定 4)→ 1 区間(未設定 0)。**外した区間が全部消え、作り直すと乱した操作が正解になる** |

- 作り直しのずれは JetFormer の `dataset._aligned_arrays` の既存の性質(シミュレーターのフレームの間隔 33,333/33,334 µs に `int(1e6/30 · (k+1))` で時刻を足す)で、
  r2 の変更が生んだものではない。ただ modes.json の「mode = 0 はシーンタブへの展開でも残る」は、展開までは正しいが、そこから作り直すと 1 フレームずれで漏れる。
- 漏れの量は小さい(作り直しでは 1 出来事あたり最大 1 観測・正解 10 個のうち 1 個)。ジャンルの付け直しは、ユーザーがシーンタブで普通にする操作なので、こちらのほうが危ない。
- そのほか確かめたこと: 取り込みの道は `PUT /api/datasets/import`・`/api/sim/datasets/<id>/import`(`sim/web.py`)・ユーザーの `jetformer_upload.py`(PUT /api/datasets/import)
  がどれも `import_archive` を通る。Hugging Face からのダウンロード(`hf_export.download` → `extract_dataset_tar`)は通らないが、元が JetFormer で外したデータセットなら npz に外しが入っている。
  強化学習モードのシーンの見分けは、アプリが `context.teacher` に方策の metadata を最後に広げる(`dist/app.js` 135〜136 行)ので `schema = jetformer-sim-rl-teacher/v1` が残る。
  ZIP 自体には外しが入らないので、この Jetson 以外(上流の JetFormer など)で ZIP をそのまま学習すると、乱した操作が正解になる(mode.json の import_requirements に書かれている)。
