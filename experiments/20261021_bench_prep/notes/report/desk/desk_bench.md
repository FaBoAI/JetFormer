## 2. 定義(結果を見る前に決めたもの)

- 予測は PyTorch FP32(best・last の重み)。10/12・10/13・10/15 に保存した予測はそのまま読み、新しい 3 本(SLOW・WGT・AUG)はこの段で同じ手順で作りました。
  - 手順が同じことの確かめ: B の best を予測し直すと、10/12 の保存と最大 0.0 µs の差(crosscheck_B.json)。
  - B の L1 は 10/15 の値と一致(best 49.144・last 49.091・介入 129.501 µs)。
  - ENS は v0-s2 と msf-s2 の予測の平均です(ens_average と同じ。S4 で、まとめた best.pth と 0.00009 µs 以内)。ENS の last は 2 本の last の平均です。
- 集合
  - primary: 保留の人の走行 4670 フレーム(pred_table part 0・human_clean_scenes・future_valid&vehicle_valid・2.5G の前後を除く)
  - interv: 介入の集合 intervention_val_20261011 の採点するフレーム 1570
  - r1_pre1s: primary のうち R1 の起点(label_events.course_anchors)の手前 1 秒 340 フレーム・起点 12
  - lowspeed_heldout: primary のうち速さ < 1.0 m/s の 222 フレーム
- l1: 10 ステップ × 2 の |予測 − 人| の平均 [µs](PyTorch FP32。best・last の重み)
- r1_app_thr_diff_us: [ta − 1.0, ta) の 予測スロットル − 人のスロットル(行 index 2 = 先読み 3)の平均。正 = 人より緩める
- steer_amp_ratio: primary の予測ステアの標準偏差 ÷ 人のステアの標準偏差(10 ステップまとめて・best)
- brake_lowspeed_frac: v < 1.0 m/s のフレームで、予測の 1 行目のスロットル > 1598 µs の割合(保留 FP32 + 10/10 の AI 走行 TensorRT)
- engine_ok: engine_check.json が今のエンジンのもので accuracy_ok・actions_max_us ≤ 2.5
- sanity_ok: 10/10 の AI 走行 11 本の AI のフレームを TensorRT(ジャンル 5・基準の設定)に入れ、NaN・Inf なし・[10,2] がすべて 500〜2500 µs・check_io が通る
- trt: engine_check.json の run_numpy(走行と同じ呼び方)の中央値・99% 点 [ms]
- r1_app の 90% 区間: R1 の起点(12 個)のかたまりを復元抽出(2,000 回・種 0・百分位)。B との差は同じフレームの差を同じ方法で。
- sanity の幅 500〜2500 µs: 12:33 の 200 フレームの試しで、ステアが 1000 µs を少し下回る値(908〜1005 µs)がほぼ全部に出ました。人の正解も 983 µs まであります。走行は 1000〜2000 µs に切るので、壊れたモデルを見つける幅として 500〜2500 µs にしました。1000〜2000 µs の外の数は参考に出します。**本番の全フレームを見る前に決めました。**

## 3. 読み方

### 3.1 門

- 候補 8 本は、すべて門に合格しました。B も engine_ok・sanity_ok が合格です(protocol の「B が false なら 10/23 は走らずに知らせる」には当たりません)。
- SLOW は A1 の門で合格しました。
  - ステアの L1 は 54.6 µs(B 50.9、差 +3.7)。brake_lowspeed_frac は 0.0035(≤ 0.01)。
  - A1 が無ければ、全体の L1 の差 +14.2 µs で落ちていました(desk_bench.json の gates_without_A1)。
- B には engine_check.json が無かったので、この段で作りました(差 最大 0.947 µs・run_numpy の p99 2.49 ms)。エンジンは作り直していません。
- AUG の代わりの slow-s1 は作っていません(AUG が出来たため)。「作れず」の候補はありません。

### 3.2 保留の L1 は差が小さい

- B は 49.1 µs です。候補(SLOW を除く)は 46.4〜50.8 µs で、B との差は −2.7〜+1.7 µs です。
- 実用の目安 10 µs と、人の揺れの床 約 31 µs より小さい差です。**机上では順位を決められません**(前からの見立てどおり)。
- いちばん小さいのは ENS(46.4 µs、−2.7)です。10/15 の −2.6 µs と同じです。
- SLOW は 63.4 µs(+14.2)です。スロットルの正解を緩めたためです。
  - スロットルだけの L1 は 72.1 µs(B 47.4)。ステアだけは 54.6 µs(B 50.9)。
- 候補は 1 本ずつ(種 1 つ)です。種の違いの幅は、同じ作り方の保存した予測で見ました(1.4 の表)。
  - B と同じ作り方の 5 本(A の種 0〜3 と B)で、保留の L1 の幅は 1.2 µs です。
  - ENS の −2.7 µs はこの幅より大きいです。ほかの候補の差(−0.3〜+1.7 µs)は、この幅と同じくらいです。

### 3.3 介入の集合(desk_key の 1 番目)

- 小さい順: ENS 117.3・AUG 123.6・SIM 124.7・ACT 125.4・WGT 128.2・B 129.5・MSF 129.7・TCP 134.0・SLOW 140.3 µs。
- 種の違いの幅(1.4 の表): B と同じ作り方 5 本で 2.9 µs、多段型 4 本で 10.2 µs(MSF の種 0 だけ 129.7、ほかの 3 本は 119.6〜120.5)。
  - B との差が 5 µs を超えるのは ENS(−12.2)・AUG(−5.9)・SLOW(+10.8)です。SIM(−4.8)・ACT(−4.1)が続きます。
  - MSF(種 0)は多段型の中で目立って大きく、多段型の形としては不利に出ています。desk_key は決まりどおり MSF の値で並べます。
- SLOW が大きいのは、介入の場面でも人のスロットルより緩めるためです。

### 3.4 R1 の手前 1 秒(r1_app_thr_diff_us)

- **B は −8.3 µs で、人より強く R1 に入る向き**です(90% 区間 −18.0〜+1.1)。今の課題(速く入るとぶつかる)と同じ向きです。
- **SLOW は +31.9 µs(17〜46)で、B より 40 µs 緩めます**(26〜57)。作りどおり、R1 の手前で自分で緩めます。
  - 人との差の区間が 0 をまたがないのは SLOW だけです。
- ほかは −9.7〜+1.0 µs です。B との差(同じフレームの差)は次のとおりです。
  - B より緩める(区間が 0 をまたがない): ACT +9.3・WGT +7.0・TCP +5.4・ENS +3.3 µs。
  - 区間が 0 をまたぐ: MSF +6.2・SIM +0.1・AUG −1.4 µs。
- risk の境(−10 で low でなくなる、−20 で high)に近いのは AUG(−9.7)です。B(−8.3)と SIM(−8.2)も近いです。
- **ただし、種の違いの幅が大きいです**(1.4 の表)。B と同じ作り方 5 本で −13.3〜−3.8 µs(幅 9.5)、ACT の種 0・1 で +1.0 と −13.1(幅 14.1)。
  - SLOW の +31.9 µs は、この幅のずっと外です。ほかの候補の B との差(10 µs 未満)は、種の違いと区別できません。
- 起点は 12 個(340 フレーム)だけです。人の走りの起点で測ったもので、実車の進入の速さとは別物です。参考として読みます。

### 3.5 振れ幅・推論の時間

- steer_amp_ratio は 0.971〜1.018 です。全部、low の幅(0.90〜1.10)の中です。
- 10/16 の B の「標準偏差の比 1.01」と、ここの 0.996 は、数え方(10 ステップまとめて・この集合)が少し違います。先読みの行(index 2)だけだと 0.994 です。
- trt_p99_ms は 2.43〜4.26 ms です。全部 8 ms 以下です。ENS は 2 本分なので、いちばん遅いです(中央 4.15 ms)。

### 3.6 sanity と低速のブレーキ

- 9 本とも、10/10 の AI 走行 21,759 フレームで、NaN・Inf はなく、500〜2500 µs の中でした。
- 1000〜2000 µs の外(走行が切る値)は 0.08〜1.2% です。すべてステアの右いっぱい(1000 µs 未満、最小 882〜984 µs)です。ステアの最大は 1982 µs 以下、スロットルは 1066〜1748 µs で、どちらも中に入っています。人の正解も 983 µs まであります。
- **低速でブレーキ側を出す候補があります(門には関係しないが、当日の注意)。**
  - 10/10 の AI 走行の低速(< 1.0 m/s)2,326 フレームで、1 行目のスロットルが 1598 µs を超えた数:
    SIM 203(8.7%)・WGT 140(6.0%)・ACT 52・TCP 39・AUG 26・B 21・SLOW 9・ENS 5・MSF 0。
  - SIM・WGT は、ほとんど止まった場面(速さの中央 0.0 m/s)です。衝突の前後でないものも多いです(SIM 66%・WGT 49%)。
  - 場所(後から見た判定)は、SIM は R1 が 125/203、WGT は R1 47・その他 63・LH 25 です。
  - 保留の人の走行の低速 222 フレームでは、どの候補も 0 です(人の正解も 0)。
  - 走行は esc_reverse 1(後退を受け付ける)なので、止まったときに後ろへ動く出力になりえます。SIM・WGT を走らせるときは、止まったときの動きを見てください。
  - 門(brake_lowspeed_frac ≤ 0.01)は A1 で label_r1 だけです。SIM 0.080・WGT 0.055・ACT 0.020・TCP 0.015・AUG 0.010 は、ほかの家族なので門で落としません。
