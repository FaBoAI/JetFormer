## 4. 1 ブロックの操作

- 10/23 と同じ(`runbook_20261023.md` の 3 章): ブロックを押す → モデル名を読み上げて照らす → 初めてのモデルは dry run → もう一度ブロックを押す → 説明欄に `battery=#__ V_before=__ check=__` → 走行開始 → CH3 を AI 側。
- 慣らしは全ブロック K = 2(R1 の入口の 2 つ目から数える)。B+上限だけ K = 3。
- 「AI の時間」が 5:00(B 案の T1・T2 は 6:00)を過ぎたら、次の直線で CH3 を人側 → 停止。
- 走ったら、シーンの説明に `V_after=__`(止めたら `memo=安全で中止` など)。紙にも書く。基板の再起動の数を控える。

### 4.1 B+上限のブロック(A 案だけ)

1. ブロック 8 を押す(モデル B・基準の値が入る。**上限のスイッチは ON にならない**)。
2. 走行タブの「区間の速度上限を出力に掛ける」に印 → 確認(G1・了承・4 つめの上限)を読んで OK。
3. 走行開始 → CH3 を AI 側。**最初の 2 周で**、「区間の速度上限」の行の区間の名前が変わる(unknown → R1_app → R1_turn など)ことと、「出力を変えたフレーム」の数が増えることを見る。2 周で変わらなければ止める(「動かず」と書く)(A6)。
4. **R1 の旋回中にブレーキが出たら中止**(目で見る。画面の区間の名前は R1_app のまま見えることがある)。
5. 終わったら、スイッチが **OFF** に戻ったのを見てから、ブロック 9(B)を押す。

## 5. 止める条件

- 10/23 と同じ(`runbook_20261023.md` の 4 章。A2: 同じ場所で、止まって CH3 で取り返した衝突が 3 周続いたら、その走行を止める)。
- 加えて: B+上限で R1 の旋回中にブレーキ → その走行を止め、B+上限は「安全で中止」。上限は OFF のまま次へ。
- いつでも: Jetson が落ちたら、すぐ CH3 を人側へ。強い正面衝突のあとは「点検する」。
