## 4. 速度上限の接続(jetformer/drive.py・safety_caps.py)

- 新しいパラメータ `zone_caps`(0/1)。safety_caps.py の v1.1(R1 2.5・GM 2.2・DE 3.0 m/s)を、車へ出す直前のスロットルに掛けます。
- **既定 OFF**。DEFAULT_PARAMS は 0 で、起動のたびに 0 に戻ります(保存値に 1 があっても 0 で起動)。
- **走行中は ON にできません**(画面とサーバーの両方で断る)。OFF にはできます。
- 前進を弱めるだけで、速くはしません。舵は変えません。
- **影の判定**: OFF でも、毎フレームの区間・上限・「上限ならこう出した」スロットル・ブレーキを AI_CMD.npz の `cap_*` の欄に残します。10/23 の記録で、ほかの候補の走りでも上限が掛かったはずの場面を数えられます。
- 計算で例外が出たら、その走行の残りは上限を外し(OFF と同じ出力)、記録と画面に理由を出します。
- 1 フレームの時間は平均 0.15 ms ほど増えます(p99 0.46 ms 以下)。
- **4 つめの上限**: v1.1 は、位相が不確かなとき(走行の始め〜最初の R1・R1 から 16 秒を超えたとき・1 秒以上止まったあと)も 3.0 m/s で切ります。了承は 3 区間だけなので、画面に赤い注意を出しています。ON の再了承のときに一緒に確かめます(9 章)。
