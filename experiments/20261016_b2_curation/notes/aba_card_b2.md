## 5. 止める決まり(計画 3 章と同じ)

- **CH3 は人が持ちます。** いつでも取り返せるようにします。
- **止まる衝突**は、すぐ CH3 で取り返します(リカバリーを待たない)。
- 次のときは、その走行を終えます。
  - 同じ場所で 2 回続けて強い衝突
  - 最初の 10 周で衝突が 20 回を超えた
- **強い正面衝突**の後は、ライブ・収集タブの「点検する」をしてから続けます。
- **Jetson が落ちた**ら、すぐ CH3 を人の側へ戻します。PCA9685 は最後の出力を出し続けることがあります。

## 8. 判定(先に決めておく)

B はブロック 1 と 3 を合わせて、B2(ブロック 2)と比べます。

**R1 が遅くなった**(B2 の効き)
- 片側 Mann–Whitney(B2 < B)で p < 0.05、かつ Hodges–Lehmann のずれ(B − B2)が 300 eRPM 以上。

**悪くならない**(4 つとも)
1. R1 の強い衝突/通過: B2 ≤ B × 1.1 + 0.02
2. DE の衝突/通過: B2 ≤ B × 1.1 + 0.02
3. 衝突/周の比(B2/B): 点推定 ≤ 1.1、かつ上側 95% 限界 ≤ 1.5(ポアソンの正確な区間)
4. 衝突なしの周の中央値の悪化 ≤ 0.3 秒、かつステアの反転/秒 ≤ B × 1.1

**まとめ**

| 結果 | 条件 | 次の手 |
|---|---|---|
| **B2 が良い** | R1 が遅くなった + 悪くならない 4 つ | B2 を次の基準の候補にする(安全層と組み合わせるかは別に決める) |
| **害なし・効き不明** | 悪くならない 4 つだけ | B のまま。B2 は保留(新しい精度データで作り直す) |
| **B2 は悪い** | 1〜4 のどれかが崩れた | B のまま |
| **判定できない** | B のブロック 1 と 3 の差が大きい(R1 の進入の中央値が 300 eRPM 超、または衝突/周の比が 0.67〜1.5 の外)。または 3 で、点推定は ≤ 1.1 なのに上側の限界だけが 1.5 を越えた(数が足りない) | 次の実車で、B2 と B のブロックを 1 つずつ足して判定し直す |

**見込み**
- 43 対 44 通過の Mann–Whitney では、約 500〜600 eRPM のずれを約 80% で見つけられます。
  - R1 の進入の標準偏差(10/10 の AI 006/007 で 893、人で 1,085)の 0.55 倍です。
- 机上の 30 µs は、定常の対応表で約 800 eRPM です。
- **固定設定の B が、もう遅く入っていたら、ずれは小さく見えにくくなります**(2 章の飛ばす条件)。

## 付録: 速度上限を常に使うことにした後の版

- B と B2 の両方で、同じ上限(R1 2.5・GM 2.2・DE 3.0 m/s)をオンにして走ります。
- 主に見るものは、次の 2 つです。
  - R1 で上限がブレーキ・減速を出した通過の割合
  - 上限に入る前のモデルの R1 の進入 eRPM(AI_CMD の上限の前の出力から見積もる)
- B2 が R1 を遅く入るなら、上限の出番が減ります。
- 「悪くならない」4 つは同じです。
