🎮 シミュレーター本体 

          

          
Jetson の ~/sim に置いたシミュレーターの ZIP(course-simulator-complete.zip など)から導入します。
            ZIP の全ファイルを COMPLETE-MANIFEST.json と照合し、取り込み済みの大きなデータ(dataset-downloads/)は入れません。
            本体(Python・JS)はブラウザからは入れられません。

          

          

        

        

          
Python 環境(ブリッジ用) 

          

          

            
            
          

          
data/sim/venv に numpy・opencv(ヘッドレス)・onnxruntime(CPU 版)を、版とハッシュを固定して入れます(数分・約 290 MB)。
            JetFormer の Python 環境には何も入れません。最後にブリッジの自己診断を行います。

        

        

          
ブリッジ 

          

          

            
            
          

          
ログ

          
ブリッジは学習済みモデルの推論(ONNX)と、集めたデータの保存を受け持ちます。推論は Jetson の CPU で動きます(GPU は使いません)。学習中は遅くなります。

            管理画面(jetformer-web)を再起動すると、ブリッジも止まり、収集中のデータは失われます(起動し直すにはこのボタンを押します)。

            同時に AI で走らせられるのは 1 つのタブだけです(ブリッジのモデルは 1 つ)。

        

        

          
🤖 強化学習モード(データセットのばらつき) 

          
シミュレーターの教師の走り方を、強化学習(RL)で学習した方策に変えて、いろいろな走りのデータセットを作ります
            (最速・壁から離れて走る・わざと乱してから立て直す・速さを変える など)。Default コースだけで使えます。
            数字はシミュレーターの中の試験の結果で、実車の保証ではありません。ジャンルはどれも 8(シミュレーター)で、モードはタグ(sim-rl-…)で分かれます。

収集プラン(モード × 分)

          
1 分 = 20 秒のシーン 3 つ。シーンの開始・種・条件は、前もって Node で走らせて 20 秒を走り切ると確かめた組から選びます。
            開くと新しいタブのシミュレーターで「開始」を押すだけで、1 シーンずつ記録し、モードごとに 1 つのデータセットに取り込みます(乱した操作は学習から外します)。
            Jetson の Firefox では 1 シーン約 70 秒(5 分のモードで約 18 分)、Mac の GPU のブラウザならもっと速く記録できます。記録中はそのタブを表に出しておいてください。

コースを追加(ZIP をアップロード)

          
          
          

          
コースの ZIP の形式・作り方
            
受け付ける形式は 2 つです(どちらも ZIP。中身が 1 つのフォルダーの下にあってもかまいません)。

            
    
              
  • JetFormer 形式: course.json({"format":"jetformer-sim-course/v1", "name", "world_version", ["id"], ["description"], ["visual"]})+ physics-world.json + 任意の assets/*.jpg|png
    • 
              
  • シミュレーターのスナップショット形式(qa/course-snapshots と同じ): manifest.json + physics-world.json [+ scene.js・world.js]
    • 
            

            
いちばん簡単な作り方: コースの「書き出し」で雛形の ZIP を取り、physics-world.json(壁・柱・路面・ゲート列・開始位置)を編集し、
              course.json の world_version と id を新しい名前に変え、world_hash の行を消してからアップロードします。world_version はコースごとに一意にしてください。

            
アップロードした JS(scene.js・world.js)は実行しません。シミュレーターのページは JetFormer と同じアドレスで動くため、JS は実車の走行 API も呼べてしまうからです。
              アップロードしたコースは JetFormer の汎用描画(簡易描画)で表示します。カメラ画像は Default とは同じにならないので、AI の評価結果は Default と直接は比べられません。
              JS は、導入済みのシミュレーター本体のファイルと完全に一致するときだけ使います。
