# 止まってから 3 周(tools/standing_3lap.py)

- 止まってから 3 周 = 3 周目の終わり(「3 周目の終わりの起点」A4 から、発進の場所 → A1 の車輪の距離だけ戻った時刻) − 車が動いた時刻(前へ 0.2 m/s)。AI 側から = − AI 側にした時刻。距離の 3 周 = analysis_tt.md 5.2 の作り方(参考)。
- 起点は section_scorecard の R1 の起点(偽の起点を外したもの)。衝突は label の決まり(水平 2.5G、強い = 4G 以上)。
- 衝突(強)はその発進から 3 周目の終わりまで。同じ本の中で、それより前に衝突がある発進は「数えない」(ぶつかったあとに人が止めて戻した発進。quick_eval_by_params の 1 章・2 章にも入れない)。
- 途中で変えた = 走行中に設定を変えた本(events.jsonl の params・log.json の params_end・天井と自動合わせの途中 OFF・発進の前進の終わり 10・フレームのゲインやトリム)。3 周目の終わりより前(か時刻が分からない)に変えた発進は数えない(手順書 7 章「走行中に OFF にした本は数えない」。最速・quick_eval_by_params の 1 章・2 章に入れない)。
- 衝突(人側にした直後も)= 2 章の衝突(強)は、AI 側の衝突と、人側にした直後(AI の区間の終わりから 0.5 秒以内)の人側の衝突(car_check の「衝突」の行と同じ数え方。人が当たる直前に CH3 を人側にした当たり。手順書 7 章の「8G 以上 1 回」「同じ場所で 2 本続けて」「左 4.2 で SW の出口・LH」に数える)。「(うち人側にした直後 N)」がその数。1 章の「前の衝突」(数えない)と、その発進から 3 周目の終わりまでの衝突(強)も同じ数え方。走りながらの 3 周の窓(ずっと AI 側の周)は AI 側だけ。
- リカバリー中止のあとの走り直し = 同じ本の中で、一つ前の AI の区間がリカバリー中止(中立で人を待つ)で終わり、CH3 を人側 → AI 側にした発進。中止で止まった所(コースの途中)から出たかもしれない(手で HS に置き直しても車輪の距離は 0 なので、記録からは分からない)ので、止まってから 3 周を数えない(最速・quick_eval_by_params の 1 章・2 章に入れない。⑤ collect.py の ON/OFF の比べにも入れない)。その 3 周の衝突は 1 章・2 章の衝突に入る。
- 「リカバリーの途中 X 秒から Y 秒」のリカバリー中止のあとの走り直し = 一つ前の AI の区間が、リカバリー(当たった・止まったあとのブレーキ・後退・前進など)の途中で人が CH3 を人側にして終わった発進(X = その区間の最後のリカバリーの始め・Y = 人側にするまでの秒)。当たった所・止まった所(コースの途中)から出たかもしれず、HS に置き直したかは記録から分からないので、上と同じに数えない(2026-10-28 fix8。main session の決め = approvals 8「fix7 で残した読み方」①)。
