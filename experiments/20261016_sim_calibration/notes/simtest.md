## 0. 結論(先に)

1. **R1 に効くかは、このシミュレーターでは確かめられませんでした。** 較正後(P_cal)では、上限なしでも R1 の衝突が 0 回でした(456 回の通過)。
   - 運転手が R1 に入る速さは、最高でも 2.74 m/s でした。実車の AI が R1 でよくぶつかった 3.1 m/s 以上には、1 回も届いていません。
   - LH(左の U ターン)で曲がりながらの減速(こすれの項)が大きく、LH の出口の速さが上がらないためとみられます(PP は速さの表どおりに指令しても、LH では表より遅くなる)。
   - 実車との突き合わせの v20(R1 の衝突の確率が 20% になる速さ)は、衝突が 0 なので出せません。**P_cal の R1 は、実車より甘い可能性があります。**
2. **GM の上限 2.2 m/s は、はっきり効きました。** 運転手 RL-speed-0.75 は、上限なしだと 24 本のうち 18 本が GM の出口の外の板にぶつかりました。
   - 実車の hotspot「GM_out」と同じ場所です。
   - 上限ありでは GM の衝突が 0 本になり、60 秒を走り切ったのは 3 本から 23 本に増えました。
   - 衝突/周の差は −0.45 です(90% 区間 −0.70〜−0.30)。
3. **決まりどおりの判定は、P_cal で「直す」です。** 理由は、運転手 RL-fastest で、衝突/周の差の 90% 区間の上端が +0.42 だったことです(決まりは +0.05 以下)。
   - RL-fastest は、上限のあり・なしにかかわらず、24 本とも SW から HS への出口の外の支柱にぶつかります。この場所に上限はかかっていません。
   - 上限ありでは、そこまでに走る距離が短い開始が多く、1 周あたりの衝突が増えて見えます。
   - 上限ありでは、R1 の内側の柱への衝突も 1 回ありました(0.91 m/s の低速で内側に切り込んだ)。
   - **上限で遅くなると、上限を知らずに学んだ方策の線が変わる**、という仮説が立ちます。実車の A/B/A で見るべき点です。
4. **ラップの損は、決まり(PP-1.0 と PP-1.2 で +0.3 秒/周以下)を満たしませんでした。** PP-1.0 は +0.18 秒ですが、PP-1.2 は +0.31 秒でした。
   - 損の大部分は DE の上限 3.0 m/s です。PP は上限なしだと DE で 3.5〜4.1 m/s 出しています。
   - R1 の上限は、PP にはほとんど掛かりませんでした(R1 の進入は 2.0〜2.2 m/s)。
5. **不変条件はすべて 0 です。** 旋回中・GM・DE でのブレーキ、1 m/s 未満でのブレーキの始まり、0.2 秒未満の往復、指令を大きくしたフレーム、後退が、どれも 0 でした。
   - P_cal では、上限の層は一度もブレーキを出しませんでした。持ち上げる(中立にする)だけで上限まで落ちたためです。
   - そのため、ブレーキの弱め・強めの結果は名目と同じです。
6. **較正で、失敗する場所が変わりました**(判定の決まり「calibration_matters」)。
   - 較正前(P_default)の判定は「どの区分にも当たらない」で、P_cal の「直す」とは違います。
   - P_default では、PP-1.2 が R1 の外側の柱に 24 本とも当たりました。上限ありでも 24 本です。PP-1.4 は LH で 23〜24 本当たりました。
   - P_cal では、失敗は GM の出口と SW の出口に移りました。
7. **ブラウザの S-DIV**(10/15 の JetFormer、実際の画面。確認だけで判定には使わない)
   - 完走は、較正前 5/12 → 較正後 0/12 → 較正後 + 上限 0/12 でした。
   - 較正の物理では、最初の LH で曲がり切れません。S-DIV は今の物理(左いっぱい 2.2 /m)で学んでいるので、**較正の物理で学び直しが要ります**。
   - index.html の E0 は、10/15 と操作列・軌跡まで同じでした(7 章)。

**次の一歩の提案**(決めるのはユーザー)

- 上限の層は、このまま**シャドー**(記録だけ)で実車#1 の A/B/A に入れるのがよいと考えます。
  - 理由: R1 に効くかが、シミュレーターでは確かめられない。DE の上限はラップの損の主な原因。
- 実車で効かせる候補は、**GM 2.2 だけ**です(シミュレーターでは効いた)。
- DE の 3.0 は、損の割に効いた場面がほとんどありませんでした(DE の衝突は RL-speed-0.75 の 1 本だけ)。外すか上げる(3.3 など)ことを、実車#1 の記録で決めるのがよいと考えます。

| 運転手 | 完走 | 衝突(区間・相手) | R1 衝突/通過 | R1 の進入の中央値 | 周の損 |
|---|---|---|---|---|---|
| PP-1.0 | 24 → 24 | 0 → 0 | 0/135 → 0/131 | 2.37 → 2.34 | +0.39 秒 |
| PP-1.2 | 0 → 0 | R1 24 → R1 24(ショートカットの開口の外側の支柱の脚 (1.26, 0)) | 24/28 → 24/28 | 2.74 → 2.49 | +0.50 秒 |

- P_default では、PP-1.2 が R1 の外側(曲がり切れない側)の柱の脚に 24 本とも当たります。上限ありでも 24 本です。
  - 進入を 2.74 → 2.49 m/s に下げても、R1 の中の速さ(約 2.3 m/s)がこの物理の R1 の限界(約 2.1 m/s)を超えているためです。
  - R1_turn の上限 2.5 は、それより高いので効きません。
- RL-fastest の R1 の衝突は 1 → 0 でした。ただ 1 回だけなので、差の 90% 区間の上端は 0 です(決まりは < 0)。
- **較正で変わったこと**
  - P_default で効いた場面(R1 の外側への曲がり切れなさ)は、P_cal では起きません。
  - P_cal で上限が効いた場面(GM の出口の外の板)は、P_default では起きません(RL-speed-0.75 は 24 本とも完走)。
  - P_default は、RL の先生が学んだ物理です。P_cal は、実車の 10/10 のログに合わせた物理です。
  - 実車の衝突の場所(R1 の外側の白い板・GM_out・DE)のうち、**P_cal は GM_out を、P_default は R1 の外側を再現**しています。どちらか一方の物理だけで、実車の全部の失敗は出ません。

## 4. 決まり(protocol の decision_rules)の判定

| 決まり | P_cal(主) | P_default(較正前) |
|---|---|---|
| 判定に使える運転手(上限なしで R1 の通過 ≥ 30、かつ 2.5 m/s 超の進入 ≥ 20%) | **RL-speed-0.75 だけ**(48 回・98%)。PP は 3 つとも 2.5 超が 0%(「上限が効く場面が無い」)。RL-fastest は通過 24 回 | RL-fastest(157 回・80%)・RL-speed-0.75(156 回・100%)。PP-1.2 は通過 28 回、PP-1.4 は 4 回 |
| R1 に効いた(相対 50% 以上減り、差の 90% 区間の上端 < 0) | RL-speed-0.75: 効かない(上限なしでも R1 の衝突 0) | どちらも効かない(RL-fastest 1 → 0 で上端 0、RL-speed 0 → 0) |
| ほかで悪くならない(衝突/周の差の 90% 区間の上端 ≤ +0.05) | **RL-fastest が破れる**(−0.08〜+0.42。HS で +0.14/周の印)。ほかの 4 つは満たす(RL-speed-0.75 は −0.70〜−0.30) | 5 つとも満たす |
| ラップの損(PP-1.0・PP-1.2 で +0.3 秒/周以下) | PP-1.0 +0.18 秒(満たす)、**PP-1.2 +0.31 秒(満たさない)** | PP-1.0 +0.39 秒・PP-1.2 +0.50 秒(満たさない) |
| 不変条件(上限ありの全走行で 0) | 0(満たす) | 0(満たす。ブレーキは PP-1.4 で 240 フレーム、RL-fastest で 28 フレーム、どれも R1_app の中) |
| **判定** | **直す**(ほかで悪くなるが破れたため) | **どの区分にも当たらない**(支持の条件を満たさない。判定に使える運転手はいるが、上限なしでも R1 の衝突がほぼ無い) |

- 「直す」の中身は、RL-fastest が SW の出口で毎回ぶつかることです。上限はこの場所に掛かっていません。
  - 上限ありでは、そこまでに走る距離が短い開始が多く、1 周あたりに直すと増えて見えます(開始ごとの走った周は、0.09〜2.6 周で上下に動く)。
  - R1 の内側への切り込みが 1 回あります。これは上限による悪化と数えるべきものです。
  - 決まりは文言どおりに当てています(deviations D26)。
- **R1 2.75 と 2.5 の比べ**: R1 の衝突が減った条件が無いので、「2.5 の減り方の 80% を出せるか」は出せません。
  - ラップの損は、PP では同じです(PP は R1 で 2.5 を超えない)。
- **ブレーキの頑健さ**: P_cal の上限の層は、ブレーキを 1 フレームも出しませんでした。ブレーキの弱め・強めの結果は名目と同じです。
  - 「ブレーキ表の実測(計画項目 8)が前提」かどうかは、このシミュレーターでは分かりません。

## 8. 実車の A/B/A(実車#1)への意味(どれも仮説)

   - 実車の GM_out の接触(10/10 の記録)と同じ場所です。

   - RL で、R1 の内側への切り込み(0.9 m/s)と SW の外への膨らみ(電池 0.8)が出ました。
